# logo-crowdworks-lp

ChatGPTでロゴの案を作り、ランサーズのコンペに提案して、納品するまでを解説する、Instagram特典配布LPです。
[lp-template](https://github.com/ryooh18-byte/lp-template) の最新版をもとに作成しています（固定部分はテンプレートのまま）。

`index.html` 1ファイル（CSS・JS内蔵）＋ `assets/` で完結します。

> ローカルのフォルダ名は `logo-crowdworks-lp`、GitHubのリポジトリ名は `Chatgpt-logosakusei` です。中身はランサーズ中心です。

## 内容

| 場所 | 内容 |
|---|---|
| このガイドについて | 「年金だけじゃ不安な50代の方へ」。クラウドワークスより、AIを使ってよいコンペが見つけやすいサイト＝ランサーズ。お金のこと（システム利用料など） |
| STEP 1 | 用意するもの（パソコン・ランサーズ・ChatGPT） |
| STEP 2 | AIを使ってよいコンペを選ぶ（絞り込み済みのボタン、見る4項目） |
| STEP 3 | 指示文に依頼内容と、「希望イメージ」のスクリーンショットを送って、ロゴを3案作る。直してもらう返信 |
| STEP 4 | コンペに提案する（生成AIの選択）。選ばれやすくするコツ |
| STEP 5 | 選ばれたら納品する。.ai（Illustrator・有料）で渡すとき |
| 補足 | クラウドワークスでも、提案できます |

## 確認した情報（2026年11月）

- ランサーズの提案ガイド・利用規約・生成AIの使用許可・制限：https://www.lancers.jp/help/guide/lancer/compe/1 、 https://www.lancers.jp/help/terms 、 https://info.lancers.jp/32193
- クラウドワークスのコンペの流れ・生成AIの使用可否：https://crowdworks.jp/pages/guides/employee/competition 、 https://blog.crowdworks.jp/archives/6516/
- OpenAI 利用規約（出力は使う人のもの。ほかの人にも似たものが出ることがある）：https://openai.com/ja-JP/policies/row-terms-of-use/
- Illustratorの体験版・画像のベクター変換：https://www.adobe.com/jp/products/illustrator/free-trial-download.html 、 https://helpx.adobe.com/jp/illustrator/desktop/manage-objects/traces-mockups-symbols/trace-images-to-convert-raster-into-vector-artwork.html
- 指示文は、ログインしたChatGPTで3回試した（画像3枚・文字・目盛りの読み取り）
